- `ARTICLE` → LL **156.605**（原 81.144 / 76.388），升至全表第 3 位。冠词用法是德语背景反馈相对通用参照最突出的语法主题之一。

- `PATTERN` → LL **54.634**：`pattern` 单独仅 4.004（勉强过显著线），`patterns` 为 59.982。合并后 54.634 虽略低于 patterns，但仍远高于 pattern，且是该词族的正确估计值。

- `MEAN`（4.635 / 4.836 → 9.061）：两个原始词形都在显著线边缘，合并后关键性明确成立——若不归并，该词族的真实关键性会被低估到几乎不可见。

## 9. 公式与校验

**4-term Log-Likelihood**：

```
O11 = Freq_Tar          E11 = N1 × (O11+O21) / N
O21 = Freq_Ref          E21 = N2 × (O11+O21) / N
O12 = N1 − Freq_Tar     E12 = N1 × (O12+O22) / N
O22 = N2 − Freq_Ref     E22 = N2 × (O12+O22) / N
N1 = 267,306（German）   N2 = 266,664（Generic）   N = 533,970
LL = 2 × Σ Oij × ln(Oij / Eij)
```

**LogRatio**：

```
LR = log₂[ (Freq_Tar / 267,306) ÷ (Freq_Ref / 266,664) ]
```

**校验**：两式对本组原始词表全部 384 条重算，与 AntConc 的 `likelihood`、`effect` 列在 3 位小数精度上**逐条完全一致**（LL 不匹配 0，LR 不匹配 0）。九个归并项由同一实现算出，口径与未归并项统一。
