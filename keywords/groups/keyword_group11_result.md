## 8. 口径说明与本组的统计特点

**本组的关键发现是「几乎没有关键词」**。除 `accurate`（LR 0.888）与 `revised`（LR 0.707）等少数几项外，入选词的 LR 普遍在 0.2–0.6 区间，效应量微弱。榜首 `your` 的 LR 仅 0.115。这与第七组（German vs Generic，`german` LR 7.351）形成极端对比。

**建议**：若研究关心的是「Baseline 与 L1 是否存在实质差异」，本组结果支持的结论是**差异极小**。若要在本组内部排序，建议改以 LR 为主排序依据、LL 作显著性门槛，否则高频词会因统计功效而非实质差异占据高位。（按你的规格第 2 条，本表仍按 LL 降序呈现。）

## 9. 公式与校验

**4-term Log-Likelihood**：

```
O11 = Freq_Tar          E11 = N1 × (O11+O21) / N
O21 = Freq_Ref          E21 = N2 × (O11+O21) / N
O12 = N1 − Freq_Tar     E12 = N1 × (O12+O22) / N
O22 = N2 − Freq_Ref     E22 = N2 × (O12+O22) / N
N1 = 271,790（Baseline）   N2 = 273,834（L1）   N = 545,624
LL = 2 × Σ Oij × ln(Oij / Eij)
```

**LogRatio**：

```
LR = log₂[ (Freq_Tar / 271,790) ÷ (Freq_Ref / 273,834) ]
```

**校验**：两式对本组原始词表全部 245 条重算，与 AntConc 的 `likelihood`、`effect` 列在 3 位小数精度上**逐条完全一致**（LL 不匹配 0，LR 不匹配 0）。本组无归并项，故表中 LL/LR 全部为 AntConc 原值。
