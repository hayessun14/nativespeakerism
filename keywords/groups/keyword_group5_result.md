## 9. 公式与校验

**4-term Log-Likelihood**：

```
O11 = Freq_Tar          E11 = N1 × (O11+O21) / N
O21 = Freq_Ref          E21 = N2 × (O11+O21) / N
O12 = N1 − Freq_Tar     E12 = N1 × (O12+O22) / N
O22 = N2 − Freq_Ref     E22 = N2 × (O12+O22) / N
N1 = 260,484（Chinese）   N2 = 267,306（German）   N = 527,790
LL = 2 × Σ Oij × ln(Oij / Eij)
```

**LogRatio**：

```
LR = log₂[ (Freq_Tar / 260,484) ÷ (Freq_Ref / 267,306) ]
```

**校验**：两式对本组原始词表全部 247 条重算，与 AntConc 的 `likelihood`、`effect` 列在 3 位小数精度上**逐条完全一致**（LL 不匹配 0，LR 不匹配 0）。本组无归并项，故表中 LL/LR 全部为 AntConc 原值。
