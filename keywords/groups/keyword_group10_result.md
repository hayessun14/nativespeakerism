## 9. 公式与校验

**4-term Log-Likelihood**：

```
O11 = Freq_Tar          E11 = N1 × (O11+O21) / N
O21 = Freq_Ref          E21 = N2 × (O11+O21) / N
O12 = N1 − Freq_Tar     E12 = N1 × (O12+O22) / N
O22 = N2 − Freq_Ref     E22 = N2 × (O12+O22) / N
N1 = 266,664（Generic）   N2 = 271,790（Baseline）   N = 538,454
LL = 2 × Σ Oij × ln(Oij / Eij)
```

**LogRatio**：

```
LR = log₂[ (Freq_Tar / 266,664) ÷ (Freq_Ref / 271,790) ]
```

**校验**：两式对本组原始词表全部 407 条重算，与 AntConc 的 `likelihood`、`effect` 列在 3 位小数精度上**逐条完全一致**（LL 不匹配 0，LR 不匹配 0）。八个归并项由同一实现算出，口径与未归并项统一。
