## 8. 口径说明与边界个案

**归并时点：R1 先行、R4 后置。** 原因：Range 无法在词表层面合并——同一文档可能同时含 `claim` 与 `claims`，相加会系统性高估分布。因此只在已通过 R1 的形式之间归并，Freq 求和、Range 取组内最大值。

按此口径被拒、但若改用「先合并再判 R1」则可能入选的家族如下。真实合并 Range 落在「最大值」与「上限和」之间，需回 AntConc 以 lemma 检索核实：

## 9. 公式与校验

**4-term Log-Likelihood**（2×2 列联表 G²，四格全计）：

```
O11 = Freq_Tar          E11 = N1 × (O11+O21) / N
O21 = Freq_Ref          E21 = N2 × (O11+O21) / N
O12 = N1 − Freq_Tar     E12 = N1 × (O12+O22) / N
O22 = N2 − Freq_Ref     E22 = N2 × (O12+O22) / N
N1 = 273,834   N2 = 266,664   N = N1 + N2 = 540,498
LL = 2 × Σ Oij × ln(Oij / Eij)
```

**LogRatio**：

```
LR = log₂[ (Freq_Tar / 273,834) ÷ (Freq_Ref / 266,664) ]
```

**校验**：以上两式对原始词表全部 530 条重算，与 AntConc 输出的 `likelihood` 与 `effect` 列在 3 位小数精度上**逐条完全一致**（不匹配 0 条）。归并项的 LL/LR 由同一实现算出，与未归并项口径统一。
